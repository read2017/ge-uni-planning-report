# 证据字段规范

## 最低字段要求

证据表中的每条记录至少包含：

- `主题`
- `结论`
- `原文摘录`
- `来源链接`
- `发布日期`
- `适用对象`
- `章节归属`
- `是否需人工复核`

## 填写要求

- `结论` 只写单一事实，不要把两个条件压成一句。
- `原文摘录` 尽量截取最小必要范围，避免长段复制。
- `发布日期` 查不到时写“页面未明确标注日期”。
- `适用对象` 需明确到学院、专业、年级或项目范围。
- `章节归属` 对应规划书中的六大章节。
- `是否需人工复核` 默认只有“是/否”两类。

## 不合格写法

- 只写“学校要求比较高”这类模糊表述
- 不附原文摘录就直接下判断
- 把建议、猜测、经验混写进证据字段
