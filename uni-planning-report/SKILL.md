# Uni Planning Report

## Overview

按“官方证据优先 + 三道人工闸门”的方式生成大学规划报告，不把 Codex 当成直接拍板的人。默认先产出来源清单、证据提取表、待确认问题清单，再起草覆盖大学四年的规划书初稿。

## Input Contract

默认必填输入：

- `学校`
- `学院`
- `专业`

可选输入：

- `学生目标`
- `成绩基础`
- `英语基础`
- `科研竞赛经历`
- `预算`
- `升学偏好`
- `就业倾向`

如果只给出 `学校-学院-专业`：

- 继续执行，不阻塞
- 先生成该专业的通用版四年规划框架
- 明确列出老师后续需要补充的个性化变量
- 不得伪造学生画像、成绩、预算、意向或背景经历

## Output Contract

每次默认交付 4 件材料：

- `来源清单`
- `证据提取表`
- `待确认问题清单`
- `规划书初稿`

必要时补充第 5 件材料：

- `质检问题清单`

输出顺序固定为：

1. 来源清单
2. 证据提取表
3. 待确认问题清单
4. 规划书初稿
5. 质检问题清单

## Non-Negotiable Rules

- 只优先使用官方来源，不把二手解读写成事实。
- 所有确定性表述必须能回溯到原文、链接、发布日期和适用对象。
- 遇到冲突信息时列出冲突，不擅自裁决。
- 不把趋势性建议写成学校硬性规定。
- 不把经验性建议写成官方政策。
- 到达人工闸门时必须明确停下，等待老师确认后再继续。
- 不自动宣称“最终定稿”。

## Three Human Gates

### Gate 1: 来源清单确认

完成来源清单后必须停下，等老师确认：

- 来源是否足够覆盖六大章节
- 页面是否确实为官方来源
- 是否需要补充院级或项目级页面
- 是否有明显过期页面需要剔除

### Gate 2: 证据提取确认

完成证据提取和冲突清单后必须停下，等老师确认：

- 抽取字段是否完整
- 原文理解是否准确
- 冲突是否需要按你的业务口径解释
- 哪些内容只能写成“待确认”

### Gate 3: 规划书初稿确认

完成规划书初稿后必须停下，等老师确认：

- 报告逻辑和语言风格
- 个性化补充点是否充分
- 风险提示是否到位
- 哪些段落需要转成更谨慎或更明确的表达

## Default Workflow

按这个顺序执行，不要跳步。

### 1. 初始化任务

- 解析 `学校-学院-专业`
- 生成标题，格式默认是 `学校-学院-专业规划书`
- 采用“面向大一入口，覆盖大学四年”的规划视角
- 不预设学生一定走保研、考研、留学或就业中的任何单一路径

### 2. 生成来源清单

优先级固定为：

1. 教育部及直属官方平台
2. 阳光高考
3. 学校本科生院、教务处
4. 学校研究生院
5. 学院官网
6. 正式招生简章、培养方案、学生手册、保研文件、转专业文件
7. 正式通知、公告、实施细则

输出来源清单时，优先复用 `assets/source-list-template.md`。  
来源规则、优先级与引用口径需要时读取 `references/source-priority-and-citation.md`。

完成后进入 Gate 1。

### 3. 提取证据

按以下主题抽取，缺项也要显式标注：

- 专业分流
- 转专业
- 绩点规则
- 核心课程
- 英语政策
- 科研资源
- 竞赛
- 保研
- 考研
- 留学
- 就业

每条都保留：

- 结论
- 原文摘录
- 来源链接
- 发布日期
- 适用对象
- 备注

冲突处理规则读取 `references/conflict-handling.md`。  
字段规范读取 `references/evidence-field-spec.md`。  
章节要点读取 `references/section-extraction-guide.md`。

输出证据提取表和待确认问题清单，优先复用：

- `assets/evidence-extraction-template.md`
- `assets/questionnaire-template.md`

完成后进入 Gate 2。

### 4. 生成通用版四年规划框架

按现有六章模板组织内容，正文模板优先复用 `assets/report-body-template.md`。

个性化信息不足时，固定列出待补变量：

- 目标路径
- 成绩基础
- 英语基础
- 竞赛/科研意愿
- 预算
- 升学偏好
- 地域偏好
- 风险承受度

写法必须是“通用建议 + 待补个性化变量”，不能假定学生已有明确画像。

### 5. 起草规划书

只能使用已经确认过的证据内容。

正文必须区分三类话术：

- `明确事实`
- `建议判断`
- `待确认事项`

写作口径、风险表述和措辞边界需要时读取 `references/writing-and-risk-style.md`。

### 6. 最终质检

按 `assets/quality-checklist-template.md` 做逐条检查：

- 是否每个关键判断都可回溯
- 是否引用了过期信息
- 是否存在未处理冲突
- 是否出现绝对化措辞
- 是否遗漏六大章节中的关键部分

只交付待老师终审版本，不宣称最终定稿。

## Chapter Requirements

默认覆盖这 6 章：

1. 基础信息与入学衔接
2. 专业详解
3. 核心课程与绩点体系
4. 科研、竞赛与背景提升
5. 升学全路径规划
6. 就业方向全景

第 5 章必须同时覆盖：

- 保研
- 考研
- 留学

第 6 章至少覆盖：

- 体制外大厂就业
- 国央企就业
- 公务员与高校规划

## Failure And Stop Conditions

出现以下情况时，不要硬写结论：

- 找不到足够官方来源
- 同一问题存在明显冲突且无法判断优先级
- 文件日期过旧，无法确认是否仍然有效
- 关键政策只存在二手转述
- 学生个性化差异会显著改变结论，但老师尚未补充信息

此时输出“缺口说明 + 需要老师确认的问题”，不要用猜测补齐。
