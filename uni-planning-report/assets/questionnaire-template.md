# 个性化补充问卷模板

## 使用规则

- 当输入只有 `学校-学院-专业` 时，先使用通用版规划框架。
- 再把以下问题交给老师或学生补充。
- 没拿到答案前，不要把这些变量写成确定事实。

## 待补个性化变量

| 变量 | 当前状态 | 建议提问 | 对报告的影响 |
| --- | --- | --- | --- |
| 目标路径 | 待补充 | 更偏保研、考研、留学还是就业？ | 决定第 5、6 章权重 |
| 成绩基础 | 待补充 | 当前成绩、排名、学习习惯如何？ | 决定保研/考研可行性判断 |
| 英语基础 | 待补充 | 四六级、口语、语言考试准备情况如何？ | 影响英语规划和留学路径 |
| 科研竞赛经历 | 待补充 | 是否参加过竞赛、科研或学生项目？ | 影响科研和背景提升建议 |
| 预算 | 待补充 | 家庭对留学、考研、培训预算预期如何？ | 影响留学和资源配置建议 |
| 升学偏好 | 待补充 | 是否接受跨专业、跨地区、跨国路径？ | 影响院校与路径建议 |
| 地域偏好 | 待补充 | 是否有城市、地区、回家乡倾向？ | 影响择校和就业建议 |
| 风险承受度 | 待补充 | 更稳妥还是更激进？ | 影响梯队和路径组合 |

## 建议补充顺序

1. 目标路径
2. 成绩基础
3. 英语基础
4. 升学偏好
5. 预算
6. 科研竞赛经历
7. 地域偏好
8. 风险承受度
